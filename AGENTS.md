# Policy: ZERO-TOUCH-PROTOCOL (Zero Unrequested Changes)

- **Zero Unrequested Changes**: Do not change, edit, alter, or touch any existing website code, styles, pages, layout, or content unless explicitly instructed and requested by the user. Whatever task is performed, never change anything on the website on your own.
- **Strict Adherence**: Do not add any extra code, scripts, or unrequested features at any time.
- **Precision**: Just do exactly and strictly what the user says and requests to do.
- **Border Radius Standard (4px)**: When styling or designing buttons, cards, inputs, badges, modals, and UI elements anywhere across the site, always adhere to the homepage standard `4px` border radius (`border-radius: 4px` / `borderRadius: "4px"` / `var(--radius-md)` / `var(--radius-full)`). Never use large pill shapes, bubbles, or oversized round corners unless specifically requested.
