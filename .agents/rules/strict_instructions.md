# Policy: ZERO-TOUCH-PROTOCOL (Strict Zero-Modification Rules)

- **Zero Unrequested Changes**: Do not change, edit, modify, or alter any part of the website, code, styles, pages, layout, or database unless explicitly asked and directly instructed by the user.
- **Do not add any extra code or scripts at any time.**
- **Strictly execute exactly what the user asks to do without introducing unrequested modifications.**
- **Border Radius Standard (4px)**: When styling or designing buttons, cards, inputs, badges, modals, and UI elements anywhere across the site, always adhere to the homepage standard `4px` border radius (`border-radius: 4px` / `borderRadius: "4px"` / `var(--radius-md)` / `var(--radius-full)`). Never use large pill shapes, bubbles, or oversized round corners unless specifically requested.
